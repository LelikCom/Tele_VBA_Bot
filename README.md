# 🤖 Телеграм-бот для оптимизации работы с Excel 📊

## 📜 Описание

Этот проект — Telegram-бот, который помогает пользователям создавать формулы и макросы для Excel на языке VBA. Он использует PostgreSQL для хранения данных и предоставляет возможность взаимодействовать с базой данных и получать статистику прямо через чат.

🎯 **Целевая аудитория** — пользователи Excel, которым нужно работать со статистикой в режиме онлайн, но которые не являются экспертами в этом инструменте.

## 🔧 Возможности

Проект включает в себя следующие функции:
- 👥 **Ролевая модель пользователей** — предоставление разных уровней доступа.
- 🛠️ **Готовые сценарии и редактирование макросов** — возможность редактировать макросы под текущие задачи.
- 🗃️ **Работа с базой данных прямо через чат** — интеграция с базой данных без необходимости выходить из Telegram.
- 💬 **Обратная связь с пользователями** — возможность получения отзывов и вопросов от пользователей.
- 📢 **Уведомления о новых обновлениях** — информация о новых функциях и улучшениях прямо в Telegram.

## 📋 Требования

Перед запуском убедитесь, что у вас установлены следующие компоненты:
- Docker 🐳
- Все зависимости, указанные в `requirements.txt`

## 🚀 Установка и запуск

### 1. Клонируйте репозиторий

Сначала клонируйте репозиторий на ваш локальный компьютер:

```bash
git clone https://github.com/LelikCom/Tele_VBA_Bot.git
cd Tele_VBA_Bot
```

2. Настройка окружения
Создайте файл .env в корне проекта и вставьте в него необходимые параметры:

```bash
nano .env
```

Пример содержимого .env:

```bash
DB_HOST=ваш_хост
DB_PORT=5432
DB_NAME=ваша_база_данных
DB_USER=ваш_пользователь
DB_PASSWORD=ваш_пароль
TELEGRAM_BOT_TOKEN=токен_вашего_бота_от_BotFather
AVAILABLE_ROLES=auth,noauth,admin,rejected,preauth
ADMIN_CHAT_ID=ID_главного_админа_с_полным_доступом
```

После вставки данных нажмите:
```bash
Ctrl+O -> Enter -> Ctrl+X
```

3. Запуск через Docker
Для запуска проекта через Docker выполните команду:
```bash
docker-compose up -d --build
```

## 📂 Структура проекта

- `bot/` — Логика работы с Telegram-ботом:
  - `commands/` — Команды бота
  - `core/` — Основная логика работы с ботом:
    - `auth_user/` — Логика авторизации пользователя и работы с ролями.
    - `handlers_admin/` — Обработчики для администраторов, например, для рассылок и работы с пользователями.
    - `handlers_for_all/` — Общие обработчики для всех пользователей.
    - `keyboards/` — Генерация клавиатур для бота.
    - `utils/` — Утилиты для работы с данными и логированием.
  - `feedback/` — Логика обратной связи от пользователей.
  
- `db/` — Работа с базой данных:
  - `seeds/` — Начальные данные для базы данных, такие как пользователи, формулы и макросы.
  - Модули для работы с пользователями, администраторами, логами и инициализацией базы данных.

- `log_dialog/` — Логирование действий бота, включая модели и обработку логов.

- `macro/` — Логика для работы с макросами Excel:
  - `convert_to_num/` — Сценарии для преобразования данных.
  - `filter_rows/` — Сценарии для фильтрации строк в Excel.
  - Общие утилиты и обработчики макросов.
  
- `docker-compose.yml` — Конфигурация для запуска проекта через Docker.
- `Dockerfile` — Конфигурация для сборки образа Docker.
- `.env` — Переменные окружения для настроек базы данных и бота.
- `requirements.txt` — Список зависимостей для проекта.
- `main.py` — Главный исполнимый файл для запуска бота.
- `README.md` — Документация проекта.
